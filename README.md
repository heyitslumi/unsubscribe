# UNSUBSCRIBE

Dark-pattern boss rush built with **Svelte 5**, **TypeScript**, **Tailwind CSS v4**, and procedural **Web Audio**.

You signed up for 5 sketchy free trials at 3:14 AM and they all auto-renew in **90 seconds**. Cancel every trial without clicking upsell traps, Hydra cookie modals, fleeing buttons, corporate buzzword captchas, or hidden ToS clauses.

## Stages

1. **CloudNote+** — Visual misdirection & triple-negative checkboxes
2. **ConsentWall™** — Hydra cookie modals, Synergy Link toggles, and Chad from Customer Success
3. **FitPulse AI** — Cursor-repelling cancel button & crying kettlebell mascot
4. **VerifyHuman** — Corporate buzzword captcha & ice-physics shuttle check
5. **OmniSaaS Corp** — Final boss: ToS landmines, fake session timeout, and A/B button swap override
